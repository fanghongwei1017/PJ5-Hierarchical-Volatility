每个交易日的文件保留原始十列：万得代码、交易所代码、日期、时间、开盘价、最高价、最低价、收盘价、成交量、成交额。解压路径形如 `sh/20170103/kline_601318.SH.csv`。八个压缩包共收录 7,009 份 CSV、1,678,159 行行情记录，文件保留原始字节。入模收益还需按报告的交易时段、区间和质量规则计算。

[逐文件索引](index.csv)列出交易日期、股票、压缩包内路径、记录行数、字节数和 SHA-256。[分股票汇总](summary.csv)给出两个时期的文件数和压缩包大小。

原实验为 6,278 份文件留有 SHA-256，本次均已重新计算并核对。中国平安的历史数据沿用当时生成的收益文件，归档中缺少对应的逐日原件哈希，因此这 731 天逐日核对了 09:31 的一分钟收盘价。索引中的 `original_sha256` 和 `archived_0931_close` 分别标明两种核对方式。压缩后再次核对了全部 7,009 个 ZIP 条目的字节哈希。
