# A股收益的分层波动模型：静态拟合与条件背景更新

经济物理学 PJ5 课程研究，提交日期：2026 年 11 月 15 日。

本仓库保存最终提交稿，以及论文对应的代码、图表、实证数据和核验记录。研究将分层随机波动理论用于本地真实 A 股行情：先拟合收益与局部方差分布，检查增加层数后的数值稳定性，再用过去交易日的收益更新背景波动，检验跨时期的分布预测。

## 数据与方法

2017—2019 年共 731 个交易日，按时间先后以 8:1:1 划分为 584、73、74 日；各段末尾留出 5 日，实际保留 579、68、69 日。只按训练期资料筛选股票：1573 只股票中 158 只满足候选条件，再按成交额中位数选取前 8 只。收益尺度和模型参数由训练段估计，更新半衰期由验证段选择。

八只股票为中国平安、贵州茅台、中信证券、伊利股份、招商银行、华友钴业、方大炭素、中国建筑。仓库提供历史 1、5、15 分钟及 2026 年 5 分钟收益，共 32 个输入文件，另有逐股逐日的筛选统计。华友钴业 2026 年仅有 45 个观测日，单独标注为短样本。

条件模型每天开盘前的状态只使用此前保留交易日的收益。整项拓展是在已有历史评估结果基础上开展的方法改进；当前结果不作为未接触测试资料的盲测证据。具体估计方法、评分口径与适用范围见报告。

## 使用

Windows 上克隆本仓库时使用下面这条命令。冻结实验含有名为 `aux` 的历史目录，需要为本次克隆放行该路径；该参数只作用于本条命令，不修改全局 Git 设置。

```powershell
git -c core.protectNTFS=false clone https://github.com/fanghongwei1017/PJ5-Hierarchical-Volatility.git
```

实验环境：Python **3.13.9**、NumPy **2.3.5**、SciPy **1.16.3**、pandas **2.3.3**。可用 `environment.yml` 建立环境；冻结协议会核对版本。`requirements.txt` 另列 Python 依赖。

在仓库根目录先检查文件完整性：

```powershell
python -X utf8 tools/verify_submission.py
```

然后按 [复算说明](docs/REPRODUCING.md) 核验实验或创建全新拟合副本。正式结果保存在仓库中，重新训练应使用仓库外的新目录。

编译报告需要 XeLaTeX、`ctex`、`pgfplots` 等宏包。从 `reports/` 执行两遍 `xelatex report.tex`；补充稿对应另两份 `.tex`。建议先复制 `reports/` 到临时目录编译。完整命令和图表说明见 [图表与排版](docs/FIGURES.md)。
