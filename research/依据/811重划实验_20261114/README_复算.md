# 8∶1∶1 划分实验复算说明

本包保存本次实验实际使用的有效收益、运行代码、参数和结果。可以从这些收益重新完成模型拟合、评分、训练日重抽样与时钟检验。它不包含原始分钟行情，也不能单凭本包重新完成全市场行情清理和选股。

2017—2019 年的 731 个交易日按日期先后分为 584、73、74 日；每段末尾剔除 5 日，实际保留 579、68、69 日。股票筛选、标准差、去季节化系数、窗口和模型参数均由新训练段重新确定。这次重划发生在已有结果被查看之后，属于回顾性检验。

## 环境和解压

正式实验使用以下环境，模型程序会核对版本和文件哈希：

| 项目 | 版本 |
|---|---|
| Python | 3.13.9 |
| NumPy | 2.3.5 |
| SciPy | 1.16.3 |
| pandas | 2.3.3 |

本机解释器为 `C:\Users\lenovo\anaconda3\python.exe`。PowerShell 的登录环境和系统 `python` 可能指向不同版本，因此下面始终指定完整路径。其他计算机需准备相同版本的独立环境，并替换解释器路径；不要在日常环境中直接覆盖依赖。对应依赖安装参数为 `numpy==2.3.5 scipy==1.16.3 pandas==2.3.3`。

将压缩包解压到一个新目录，保留 `工作文件`、`依据` 两个顶层目录及其相对位置。例如在 PowerShell 中：

```powershell
$py811 = 'C:\Users\lenovo\anaconda3\python.exe'
& $py811 -m zipfile -e '实验复算_811_20261114.zip' 'E:\PJ5_811_核验副本'
Set-Location -LiteralPath 'E:\PJ5_811_核验副本'
```

后续命令均从解压根目录执行。示例目标目录应事先不存在，避免与其他文件混合。

## 先核验已保存结果

```powershell
& $py811 -X utf8 '工作文件\811重划_20261114\fit_validate.py'
& $py811 -X utf8 '工作文件\811重划_20261114\aux_validate.py'
```

第一项独立核对日期归属、训练尺度、时段内滚动方差、逐点评分、区间点估计、扩层停止条件和高精度数值结果。第二项核对训练日重抽样记录、午休与隔夜配对日期、相关系数及区间、日内幅度统计。两项检查会重新写入各自的核验汇总，不进行整套模型拟合。

交付包在临时解压目录实际执行了上述两项检查。检查时额外限制 Python 层的文件读取范围，只允许包内文件及固定解释器环境；验证记录保存在 `delivery_manifest.json`。这是对包内依赖的检查，不等同于操作系统级隔离。运行仍需要表中列出的 Python 环境。

## 续跑与重新计算

下面的命令是哈希匹配续跑：已有结果与输入、代码、协议一致时直接读取，不代表从头重算。

```powershell
& $py811 -X utf8 '工作文件\811重划_20261114\fit_runner.py' --phase all
```

如需全新计算，先用辅助程序创建一个独立副本。程序只接受尚不存在且与源包分离的目标目录，复制收益输入、代码、冻结运行库和协议，不复制旧拟合及辅助统计结果，也不删除源包内容：

```powershell
& $py811 -X utf8 '工作文件\811重划_20261114\package_experiments.py' --fresh-copy 'E:\PJ5_811_全新计算'
Set-Location -LiteralPath 'E:\PJ5_811_全新计算'
& $py811 -X utf8 '工作文件\811重划_20261114\fit_runner.py' --phase all
& $py811 -X utf8 '工作文件\811重划_20261114\aux_runner.py' --stage all
& $py811 -X utf8 '工作文件\811重划_20261114\fit_validate.py'
& $py811 -X utf8 '工作文件\811重划_20261114\aux_validate.py'
```

辅助程序只准备目录，不会自动启动实验。本次打包自检没有重复运行整套拟合。全新拟合的计时字段和压缩文件元数据可能不同，因而结果文件哈希不要求与交付包逐字节相同；程序会为新结果重新建立哈希关联，并由校验程序检查数值和输入关系。

需要并行时，可以将模型案例分成 `--case-indices 0,3,6,9`、`1,4,7,10`、`2,5,8,11` 三组，分别运行 `--phase all`。同一个案例不要同时启动两次。辅助统计应在模型训练完成后运行。

## 文件范围

| 位置 | 内容 |
|---|---|
| `data/historical` | 八股历史有效原始对数收益，含日期、时段、频率和分段标记 |
| `data/oos2026` | 八股 2026 年五分钟有效原始对数收益 |
| `data/selected_8.csv`、`all_stocks.csv`、`eligible.csv` | 选股名单、完整股票范围和候选统计 |
| `data/*manifest.json`、`return_checks_*.json`、来源表 | 划分、质量检查、原始来源及输入哈希审计 |
| `fits/runtime` | 已冻结的数值函数和运行模块；不需要从旧实验目录载入 |
| `fits/*.base.json`、`*.depth.json` | 初始拟合、扩层及极限模型参数；两套参数分别保存 |
| `fits/*.point_scores.csv.gz`、`*.evaluation.json` | 逐点分数、分期评分、配对区间和样本量 |
| `fits/*.validation.json`、`validation_summary.json` | 高精度复核和独立总校验 |
| `fits/summary.csv` | 12 组模型结果摘要 |
| `aux` | 训练日重抽样、时钟检验、日内幅度及其核验结果 |
| `工作文件/811重划_20261114` | 五个实验与校验脚本，以及打包/创建新副本的辅助程序 |

包内共 32 个收益输入和 12 个逐点评分文件。`delivery_manifest.json` 列出文件大小、SHA-256 和解压核验结果；清单不对自身计算哈希。未纳入试跑、部分检查点、缓存、运行日志以及两张较大的逐股逐日选股中间表。

`data_prepare.py` 保留了原始数据处理和选股的审计代码，但其原始行情位于 E 盘，部分步骤还依赖旧缓存，不能在独立包中直接重跑。来源清单中的原工作区和 E 盘绝对路径也是审计记录；包内模型与辅助检查使用当前解压目录下的收益文件。若要从原始行情重做选股，需要另行取得这些源数据及缓存。

原有 60 个交易日且 5000 条收益的样本门槛没有放宽。新五分钟验证段和测试段不满足收益条数门槛；其结果保留为短留出段检验。各评分期的门槛状态见 `fits/validation_summary.json` 的 `period_sample_gates`。主例 2026 年分段检验也应同时检查样本量，不能仅凭交易日数量判断是否达标。
