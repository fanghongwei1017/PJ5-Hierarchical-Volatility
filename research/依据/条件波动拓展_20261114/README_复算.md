# 条件波动拓展实验复算包

本包包含八只股票的条件波动实验、逐点评分和核验记录。解压后保留 `工作文件` 与 `依据` 的相对位置。在解压目录打开 PowerShell，再执行下列命令。不要在交付原件中重新训练；需要重新计算时，先建立独立副本。

## 运行环境

本次实验使用 Windows、Python 3.13.9、NumPy 2.3.5、SciPy 1.16.3、pandas 2.3.3。原机器解释器为：

```powershell
$py = 'C:/Users/lenovo/anaconda3/python.exe'
& $py -X utf8 -c "import platform,numpy,scipy,pandas; print(platform.python_version(),numpy.__version__,scipy.__version__,pandas.__version__)"
```

冻结协议会检查上述版本。在其他机器上须准备相同版本，并只将命令中的 `$py` 改为该环境的绝对路径；助手启动子进程时沿用当前解释器，无须修改任何包内文件。冻结拟合脚本、数值内核和协议不应修改。

## 包内材料与依赖

- `工作文件/条件波动拓展_20261114/`：冻结的拟合脚本、独立科学核验脚本及本复算包助手。
- `依据/条件波动拓展_20261114/experiment/`：协议、验证段选出的共同半衰期、52 份训练记录、八股的参数与评估、逐点对数评分/PIT/预测方差、每日状态、数值精度核验、汇总表及所用内核。
- `依据/条件波动拓展_20261114/validation/`：已完成的独立审计、因果性与密度预检、覆盖率范围说明，以及复算包行为测试。
- `依据/811重划实验_20261114/data/`：八股在历史段和 2026 年的 16 个原始五分钟收益文件，以及筛选、划分和原输入清单。收益来自已有真实行情；“raw”表示尚未按训练标准差归一化，并非原始逐笔行情。
- `依据/811重划实验_20261114/fits/`：八份旧五分钟基线参数及原数值内核，用于核对训练尺度和旧模型比较。
- `delivery_manifest.json`：逐文件大小与 SHA-256、实际依赖、解压运行检查结果。清单自身不计入它所描述的 payload，压缩包文件数比 payload 多 1。

没有加入旧实验的十分钟输入、日志、报告图片或整套历史目录。图表与报告源码另行交付。

原输入清单是已经归档的 32 项审计记录，含原机器绝对路径，其中一半为十分钟数据。本实验实际使用 16 项五分钟输入。为保留原清单和冻结代码，助手仅在内存中选取这 16 项，并按股票代码、历史/2026 时段映射到当前解压目录；SHA-256 原样保留。它不会打开清单中的旧绝对路径，也不会改写清单。原独立审计检查了 32 项；便携复算检查本实验使用的 16 项，两者范围不要混写。

## 核验交付结果

```powershell
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/package_extension.py' --verify
```

这一步验证全部文件哈希，实际执行独立因果性/密度预检，复核验证段半衰期选择，重新计算八股的每日状态、归一化和各时段样本掩码，并逐一核对最终参数的训练来源与归档审计对应关系。新记录写入 `.package_verification_时间戳/`，归档文件保持原样。

执行时使用 Python 文件访问审计：只允许读取解压目录及 Python 安装目录，只允许向本次检查的新目录写文件，并实际测试对包外读取的拒绝。它是 Python 层的访问检查，不是操作系统沙箱。

打包交付前已经在新建的临时目录解压，并实际通过上述检查。此次检查没有重新训练，也没有重新运行全量 CDF、逐点高精度积分和区块自助法置信区间；这些科学核验的已完成结果保留在 `validation/independent_validation.json`，且逐份核对了文件与来源哈希。需要重做完整独立科学核验可执行：

```powershell
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/package_extension.py' --validate-full
```

该命令仍不重新拟合。它运行冻结独立核验器，重算全部八股的状态、逐点评分/汇总、PIT 参考、覆盖率以及 1/5/10 日区块置信区间，输出到新建的 `portable_validation_时间戳/`。它不会覆盖归档审计。

## 从头重新拟合

先从交付目录建立一个**尚不存在且位于交付目录之外**的新目录。例如：

```powershell
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/package_extension.py' --fresh-copy 'E:/PJ5_条件波动全新复算'
Set-Location -LiteralPath 'E:/PJ5_条件波动全新复算'
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/extension_fit.py' --stage select
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/extension_fit.py' --stage train
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/extension_fit.py' --stage evaluate
& $py -I -B -X utf8 '依据/条件波动拓展_20261114/experiment/validate_csv_schema.py'
& $py -I -B -X utf8 '依据/条件波动拓展_20261114/experiment/summarize_results.py'
& $py -I -B -X utf8 '工作文件/条件波动拓展_20261114/package_extension.py' --validate-full
```

`--fresh-copy` 只复制只读输入、旧基线、协议、数值内核和运行脚本，不复制本拓展的训练缓存、半衰期选择、评估或审计结果；已有目标目录会直接报错，不删除或覆盖任何文件。新目录的 `fresh_setup.json` 记录复制内容和原始哈希。

必须使用上面的 `validate_csv_schema.py` 入口做逐点高精度核验。冻结拟合脚本的原 `--stage validate` 读取 CSV 时没有固定 `block` 类型，pandas 分块推断可能将部分 `2026` 标签读成整数，导致状态核验误报。适配入口明确将日期及 `block` 读为字符串，并检查保护文件未变。不要用原 `--stage all` 代替上述步骤，因为它也会进入原校验入口。该读取问题没有改变已完成的模型拟合或评分。

全新训练后，参数与评分应按数值容差比较；耗时、运行记录等字段可能变化，不能要求整个 JSON 的哈希与归档相同。协议、代码与只读输入则应保持一致。

## 实验口径

训练/验证/测试按时间 8:1:1 划分并保留原边界间隔。收益始终使用原保留训练段的标准差归一化。训练前 60 个保留日只更新状态，新静态与动态模型均在同一后续掩码上估计参数。今日状态只依赖之前保留日的收益，边界间隔不拟合、不评分、不更新状态。候选半衰期为 5、10、20、40、60 个观测日；只用中国平安八层模型的验证段评分选择，结果为 5 日，各股共用。2026 年每股重新从状态 1 开始，分别报告全部观测和去除前 20 日的结果。

该拓展是在已查看旧样本外结果之后开展的回顾性改进，不能称为未接触测试数据的盲测。八股最终使用的优化解均成功、未触及约束边界；中国建筑存在一个未采用的失败初值，另两个成功初值的目标值相差约 `2.84e-11`，记录已保留。华友钴业 2026 年仅 45 个观测日，应作为短样本补充。不能把覆盖率记录中的关键函数 100% 说成整套程序的覆盖率。
